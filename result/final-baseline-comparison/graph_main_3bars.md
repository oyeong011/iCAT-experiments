# 메인 baseline 3막대 그래프 숫자 (2026-11-27, 승컴)

- 생성: `python3 -I -B analysis/revision/baseline_package.py`
- 입력은 `result/final-validation-20261127/final_statistical_validation.csv` 하나예요. 스크립트가 평균, SD, CI, Δ, Holm p를 이 파일의 반올림 전 값과 다시 대조해요 (assert 통과).
- 지표는 mixFYF 90분 전체 WAF이고, 낮을수록 좋아요. 모든 그룹은 n=3이에요.
- 새 실험은 없어요. Online Greedy는 이 패키지에서 뺐어요.

## 값

| 막대 | 호스트 / 배치 | 평균 WAF | SD | 95 % CI | iCAT-v4 대비 ΔWAF [95 % CI] | Holm p | 비교 방식 |
|---|---|---|---|---|---|---|---|
| Random Selection | 고컴 / revA-20261114 | 2.324 | 0.006 | [2.311, 2.338] | +0.196 (+9.2 %) [0.184, 0.208] | 9.4e-06 | direct (revA V4) |
| iCAT-v4 (revA 대조군) | 고컴 / revA-20261114 | 2.128 | 0.005 | [2.116, 2.141] | 기준 | — | 대조군 |
| iCAT-v4 (batchG 대조군) | 승컴 / batchG-20261126 | 2.110 | 0.024 | [2.050, 2.171] | 기준 | — | 대조군 |
| Greedy GC | 승컴 / greedygc-20261126 | 2.629 | 0.007 | [2.612, 2.647] | +0.519 (+24.6 %) [0.463, 0.574] | 0.0013 | direct (batchG V4) |

- **iCAT-v4는 값이 두 개예요.** Random의 대조군은 고컴 revA V4이고, Greedy GC의 대조군은 승컴 batchG V4예요. 호스트가 달라서 두 값을 합쳐 V4 막대 하나로 만들지 않았어요. 두 값의 차이는 0.018이에요.
- **Random Selection과 Greedy GC는 서로 직접 비교하지 않았어요.** 호스트와 배치가 달라서 둘 사이의 차이나 p값은 없어요. 둘 다 자기 배치의 V4와만 비교했어요.
- Holm 가족
  - revA: 3개 대비 × {전체, 단계 C} = 6이에요.
  - batchG: 2개 대비 × {전체, 단계 C} = 4예요.

## 그래프 그리는 법 (추천)

막대 3개를 그대로 쓰되, V4 막대 자리에 두 대조군 값을 나란히 그려요.

```
 Random (고컴)  │ iCAT-v4 고컴 │ iCAT-v4 승컴 │ Greedy GC (승컴)
     2.324      │    2.128     │    2.110     │     2.629
     └──── +0.196, Holm 9.4e-06 ┘            └── +0.519, Holm 0.0013 ┘
```

- 괄호선은 같은 배치끼리만 이어요. Random과 Greedy GC를 잇는 선은 넣지 않아요.
- 캡션: "Random과 Greedy GC는 각각 같은 배치의 iCAT-v4와만 비교했다 (호스트가 다름). 둘 사이는 직접 비교하지 않았다."
- 꼭 V4 막대 하나로만 그려야 한다면, 어느 대조군 값을 쓰는지 캡션에 적어야 해요. 다른 막대의 Δ는 그 막대와 같은 배치의 V4 기준으로 적어요.

**그래프에 붙일 한 줄**
> iCAT-v4는 같은 배치의 Random보다 WAF가 9.2 % 낮고 (Holm p < 0.001), 같은 배치의 Greedy GC보다 24.6 % 낮았다 (Holm p 0.0013).
