  - WAF는 iCAT V4가 Greedy GC보다 전체 약 20 %, 단계 C 약 23 % 낮다. 세 단계 모두에서 그렇다.
  - **반면 FIO 쓰기 지연은 Greedy GC가 훨씬 낮다** (평균 약 절반, p99 약 1/4).

    - 이 가설을 확인하려면 GC 선택 시간 계측이 필요하다. 이번에는 하지 않았다.
  - YCSB 처리량과 지연은 차이를 확인하지 못했다.
- 오버헤드:
  - CPU는 측정하지 않았다.
  - 학습기 경과 시간은 V4 약 4.2 ms다 (실행 1.5시간 중, ktime 기준이고 CPU 시간이 아니다).
