  - 위 수치는 **정적 단일 워크로드**에서 측정 잡음·전환 비용·탐색 구간 손실이 0이고, 한 번 고정한 뒤 워크로드가 바뀌지 않는다는 이상적 가정 하의 **하한(낙관적) 기댓값**이다.
  - 실제 NVMeVirt 온라인 Random Search(탐색 중 나쁜 arm 실행 손실 + 전환 시 재탐색 불가 문제 포함)의 실측 성능과는 별개이며, 논문에서 두 개념을 혼용하지 않는다.
