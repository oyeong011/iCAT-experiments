## 1. 독립 검증 기준 (7대 게이트)

모든 원시 실행 디렉터리는 아래 7개 항목을 Git 원시 블롭(`environment.txt`, `exit-code.txt`, `summary.txt`, `final-control.txt`, `phase-*.{txt,time,json}`, `ycsb-*.txt.gz`, `kernel.log`)에서 직접 파싱해 검증했다.

1. 모듈 파일명 및 SHA256 (`modules.sha256` 사전 등록 대조)
2. `exit-code.txt == 0` 및 FIO 모든 job `error == 0`
3. YCSB 성공률 ≥ 99% (신규 `revA`~`revD` 전 건 **100.00%**) 및 `SQLITE_FULL == 0`
4. 커널 `BUG:` / `Oops` / `WARNING:` / `Call Trace` / `EXT4-fs error` / `I/O error` == 0
5. WAF 2경로(및 3경로) 원시 카운터 재계산 일치 (`summary.txt` = `final-control.txt` 전체 = 파티션 합 `1 + Σgc/Σhost`, 오차 < `2e-6`)
6. `WATGC_V2 reset` 횟수·시점·복원 후보 수 및 `settled` 정착 검증
7. 중복 실행 여부, 큐 순서(`queue-order.registered.txt` 대 `queue.log`), CPU/`loadsampler` 계측 누락 여부
