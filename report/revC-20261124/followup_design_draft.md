- 이 문서는 제안이다. revC가 끝나고 결과를 확인한 뒤에 확정하고 사전 등록한다.

## 1. 같은 배치 noelim (revD-noelim)

**왜 필요한가**
- revB의 noelim·nosettle(n=3)은 revA-v4(n=3)와 비교되었다.
- 그런데 revB 사전 등록의 배치 연결 판정이 불합격이었다(revB-v4 2.152 대 revA-v4 2.128, +1.1 %, +4.8 SD).
- 그래서 "후보 제거가 WAF를 낮춘다"(+0.094)는 배치를 넘는 비교다.
- revC는 같은 조건의 V4를 n=3으로 새로 잰다. 여기에 noelim을 붙이면 같은 배치 비교가 된다.

**선행 확인 (revC 완료 후)**
1. revC-v4 3회가 모두 유효해야 한다(exit 0, check-run OK, YCSB 실패 0 %).
2. revC-v4와 revA-v4의 차이를 기록한다(판정에는 쓰지 않는다).
3. revC 마지막 run과 noelim 첫 run 사이에 환경 변화가 없어야 한다(커널, 부팅 인자, 모듈 해시, 상시 프로세스).

**설계**

| 항목 | 값 |
|---|---|
| 모듈 | 기존 `nvmev-revB-noelim.ko`(revB 사전 등록 해시). 또는 revC-src `ICAT_VARIANT=3` 빌드. 새로 빌드하면 revB-noelim과 기계어 비교를 먼저 한다 |
| 러너, 부하, seed, 준비, 시간 | revC와 동일(`runner-revC.sh`에 정책 1개만 추가). mixFYF 1800 s × 3. seed = revC 규칙 그대로(rep 1..3) |
| 반복 | noelim n=3 |
| 대조군 | revC-v4 n=3 |
| 시기 차이 확인 (권장) | V4 연결 run 1회를 noelim 앞이나 사이에 넣는다. 사전 판정 기준: revC-v4 범위 ± max(3 SD, 1 %) 안. 벗어나면 "배치 간 비교"로 낮춰 보고한다 |
| 순서 | noelim r1 → V4-bridge → noelim r2 → noelim r3 (또는 무작위) |
| 비용 | noelim 3 × 약 92분 = 4.6 h (연결 run을 넣으면 6.1 h) |
| 분석 | revC와 같다: 평균 ± SD, 95 % t-CI, Welch, 같은 rep끼리 짝 비교. n<3이면 통계 없음 |

## 2. E6 2차 민감도 (revC 결과 확인 뒤 필요성 판단)

한 번에 파라미터 하나만 바꾼다. 빌드는 revC-src의 `ICAT_EXTRA`(`#ifndef` 덮어쓰기)를 쓴다.

| 파라미터 | 코드 (online-v4-src) | 기본값 | 실험 근거 (현재) | 제안 수준 | 우선순위 |
|---|---|---|---|---|---|
| drift 문턱 | `WATGC_V2_DRIFT_Q16` h:58, 적용 c:534–545 | 25 % (3구간 연속, h:59) | v1의 12.5 %가 잡음으로 발동했다는 주석만 있다. 측정 없음 | 12.5 %, 50 % | 1 (재탐색 주장 M6와 직결. 승컴 E1과 함께 해석) |
| 판단 구간 | `WATGC_V2_WINDOW_GC`, `_HOST_PAGES` h:43–44, 적용 c:663 | 128 GC + 512 MiB | 고컴 로그 재분석(창 잡음 5.5–7.1 %). 측정 없음 | 64 GC/256 MiB, 256 GC/1 GiB | 2 |
| 탐색 계수 c | `WATGC_V2_UCB_C_Q16` h:51, 적용 c:438 | 0.25 (WAF 단위) | 없음(주석 "heuristic") | 0.125, 0.5 | 3 |
| 정착 조건 | `STABLE_WINDOWS` h:53, `BEST_CONFIRMATIONS` h:54 | 12구간, 3회 (허용 0.5 %, h:55) | 없음. 정착 제거 실험(nosettle)은 구분되지 않음 | 6, 24구간 | 4 |
| 재평가 주기 | `WATGC_V2_STALE_WINDOWS` h:57, 적용 c:415 | 240구간 (정착 전 탐색에서만 쓰임) | 없음 | 120, 480 | 5 |
| 할인 γ | `WATGC_V2_GAMMA_Q16` h:50, 적용 c:548–552 | 0.99950/구간 (반감기 약 1,376구간) | 없음 | 반감기 ×¼, ×4 | 5 |

- 비용: 파라미터 하나당 2수준 × 3회 × 약 92분 = 약 9.2 h.
  - 6개 모두 하면 약 55 h다.
  - 우선순위 1–2만 하면 약 18.4 h다.
- 같은 배치 V4 대조군이 필요하다. revC-v4를 재사용하려면 바로 이어서 실행하고 연결 run을 넣는다.
- 판단: 이 값들은 "설정값"이고 "검증된 최적값"이 아니다. 측정하지 않은 파라미터는 논문에 "경험적 설정, 민감도 미측정"으로 쓴다.
- 승컴 E4(mixR, 같은 일부 파라미터 계획)와 범위를 먼저 맞춘다.
