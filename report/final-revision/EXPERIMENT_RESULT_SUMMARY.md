## 3. 보조 지표 (불리한 결과 포함)

- **단계 C 첫 5분 WAF**: Greedy − revD-V4 = −0.191 [−0.289, −0.093] (간접).
  - 전환 직후에는 Greedy가 낮다. V4에 불리한 결과다.
- 같은 지표에서 V4가 낮았던 대비 (차이 있음)
  - Random +0.207
  - 원래 iCAT +0.391
  - FullReset +0.271
  - NoElim +0.388
  - Greedy GC +0.583
- 같은 지표에서 구분되지 않은 대비: V1, V2, NoDrift, 제거 문턱, 60 arms, NoDiscount, 묶음 끔, 감지 12.5 %, 감지 50 %
- 시간별 WAF (고컴 revA, 5분 창, n=3 평균)
  - 단계 C에서 V4는 2.57 → 2.36으로 낮아진다.
  - 같은 구간에서 Random은 2.77–2.85에 머문다.
- 지연
  - V4의 FIO p99가 Random보다 15–20 µs 높다 (고컴 revA).
  - Greedy GC의 FIO p99가 V4보다 낮다 (승컴 계산, 고컴은 재계산하지 않음).
  - 지연이 좋아진다고는 주장하지 않는다.

## 5. 논문에서 할 수 있는 주장과 할 수 없는 주장

- 할 수 있는 주장 (같은 배치, n=3, CI 기준)
  - V4가 Random, 원래 iCAT, Greedy GC보다 WAF가 낮다.
  - 제거와 정착을 함께 끄면 WAF가 높아진다. 묶음 끔도 마찬가지다.
  - 고정 Arm 47 결과가 재현된다.
  - 학습 상태 메모리가 SmartGC 재구현보다 훨씬 작다(계산값).
- 할 수 없는 주장
  - Online Greedy보다 낫다.
  - 변화 감지나 할인이 효과가 있다.
  - 25 %가 최적의 감지 문턱이다.
  - iCAT의 GC 경과 시간이 짧다.
  - CPU 사용 시간이 적다.
  - SmartGC보다 통계적으로 우월하다 (n=1이다).
  - 서로 다른 배치·호스트의 결과를 합친 값.
