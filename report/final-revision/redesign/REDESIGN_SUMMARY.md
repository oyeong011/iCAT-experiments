## 2. Random / Greedy 통합 그래프(`01_Main_Comparison_Baselines`)에서 무엇을 강조했는가

1. **정책 간 성격 차이와 방향성 한눈에 파악:**
   - **절대값(그래프 A):** 세 호스트·배치의 `iCAT-v4`(파랑 `2.11~2.14`)가 같은 배치의 고정/무작위/구버전 기준선(빨강: `Random 2.32`, `원래 iCAT 2.40`, `Greedy GC 2.63`)보다 일관되게 낮음을 보여준다.
   - **상대 개선폭(그래프 B):** V4 대비 Δ WAF를 내림차순으로 배치하여 **`Greedy GC (+0.519)` > `원래 iCAT (+0.275)` > `Random Selection (+0.196)`** 순으로 V4의 직접 이점이 크다는 점과, **`Online Greedy (−0.009)`는 0선 근처에서 구분되지 않는다**는 한계를 동시에 드러낸다.
2. **과잉 해석 차단:** 그래프 A와 B 바로 아래에 4대 필수 주석을 고정 배치해, 독자가 빨간 막대(`Random` vs `Greedy GC`)를 서로 직접 통계 비교한 것으로 오해하지 못하도록 원천 차단했다.

## 3. 직접 비교와 간접 비교를 어떻게 구분했는가

1. **색상 체계 분리:**
   - **같은 배치 직접 비교:** 그래프 A는 빨강(`#C0392B`) vs 파랑(`#1F5AA6`), 그래프 B는 파랑(`#1F5AA6`).
   - **다른 배치 간접 비교:** 그래프 A·B·시트 03 모두 주황(`#D97706`)으로 통일하고, X축 라벨과 범례에 `[승컴, 간접]`을 명시.
2. **통계 표기 분리:**
   - 직접 비교 3종(`Random`, `원래 iCAT`, `Greedy GC`)과 Ablation 12종만 `Holm p`를 기재.
   - 간접 비교(`Online Greedy vs revD-V4/abl-V4`, `revB−revA`, `Arm 47 vs batchG-V4`)는 `해당 없음 (간접)`으로 분리해 직접 증거와 섞이지 않도록 설계.
   - `n=1` 비교(`SmartGC m1`, `고컴 Arm 47 참고`)는 오차 막대·CI·p-value를 일절 부여하지 않음.
3. **그래프 하단 4항목 표준 메타 블록:** 11개 그래프 모두 바로 아래에 **[핵심 해석 문장] + [데이터 출처 / n / 직접·간접 비교 여부 / Holm 보정 여부]**를 의무 배치.
