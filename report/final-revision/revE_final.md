## 4. 해석 (측정 범위 안에서)

**M2: 실행 중 제거 단독**
- 정착과 변화 감지를 켠 채 제거만 꺼도 WAF가 4.3 % 높아졌다.
  - 첫 단계부터 1.7 % 높았다. 후보 45개가 계속 탐색 대상에 남기 때문이다.
  - 전환 후에는 복원할 후보가 없다. 45개 전체를 다시 탐색하므로 재수렴에 약 18분이 걸렸다.
- 배치 A의 "제거·정착 없음"(+6.4 %)은 두 기능을 함께 끈 결과였다. 이번 결과로 제거 단독 효과가 대부분을 차지한다는 것을 같은 방향으로 확인했다.
  - 배치가 다르므로 두 값의 차이를 정착 효과로 계산하지 않는다.
- Holm 보정 후 p = 0.091이다.

**M6: 변화 감지 임계값 12.5 %**
- 단계 3 감지 시점과 재탐색 규모는 대조군과 비슷했다.
- 단계 2에서 재설정이 더 자주 일어났고(1.7회 대 0.7회), 단계 3 WAF가 0.148 높았다.
- 그 원인 경로는 이 자료로 확정하지 못했다.
  - 단계 2 재설정과 단계 3 WAF 사이의 run 단위 관계는 n=3이라 검정하지 않았다.
- 결론
  - 이 워크로드에서 25 %가 12.5 %보다 WAF가 낮았다. 보정 전 기준이다.
  - 25 %가 최적값이라는 주장은 하지 않는다. 측정한 값은 12.5 %와 25 % 두 개뿐이다.
