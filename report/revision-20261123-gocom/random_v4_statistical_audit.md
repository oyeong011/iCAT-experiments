# Random Selection 대 iCAT V4 통계 재검증 (고컴 revA)

- 작성: 2026-11-23, 고컴. 새 실험은 하지 않았다.
- 입력: `result/revA-20261114/raw/mixFYF-revA-{random,v4}-rep{1,2,3}/summary.txt`
- WAF = 1 + gc_pages/host_pages. 카운터는 측정값이고, WAF는 그 카운터로 계산한 값이다.
  - 카운터가 맞는지는 `waf_recalculation_audit.md`에서 확인했다 (summary.txt = final-control.txt, 차이 5e-7 이하).

## 3. 해석 한계

1. **반복 수는 3이다.** CI는 t(df=2)를 써서 넓게 잡았다. 그래도 차이가 CI 폭의 약 16배라 결론은 바뀌지 않는다.
2. **V4의 반복 간 편차는 과소추정됐을 수 있다.** revB 브리지(같은 V4, 11-22)는 2.1520이었다. 그 값을 넣어도 V4 평균은 2.1343이고, Random과의 차이는 0.190이다.
3. **한 가지 부하뿐이다.** 승컴 E2(mixR×3)는 생략됐다(`1b94a195a`). 다른 부하에서의 Random 비교는 없다.
4. **Random 정의:** 매 판단 구간마다 45개 중 균등 추첨한다. 시작 때 하나를 골라 끝까지 고정하는 "무작위 고정 기댓값"과는 다르다. 후자는 승컴 `random_selection_audit.md` §2에 있다(1배 길이, V4 n=1).

## 4. random45 신규 실행을 생략해도 되는 근거

| 비교 항목 | 고컴 revA-Random | 승컴 random45 (생략됨) |
|---|---|---|
| 정책 동작 | 판단 구간마다 45개 균등 추첨, 학습·제거·정착 없음 | 같음 (`online-random45-src/conv_ftl.c:570–579`) |
| 난수 | rep마다 다른 seed (icat_seed) | (파티션, 구간 번호)만으로 정해서 3회 모두 같은 순서 |
| 탐색 공간 / 판단 구간 | 45 / 128 GC + 512 MiB | 같음 |
| 부하 / 호스트 / 1회 시간 | mixFYF / 고컴 / 약 1.5 h | mixR×3 / 승컴 / 약 2.5–3 h |
| 결론 | Random − V4 = +0.196, CI 폭의 16배 | — |

- 같은 질문("학습이 무작위 선택보다 나은가")에 고컴 결과가 이미 분명하게 답했다.
- random45는 반복 간에 추첨 순서가 같아서, 3회를 돌려도 대조군 편차를 제대로 재지 못한다.
- **판정:** 생략은 타당하다. 논문에는 "Random 비교는 mixFYF 한 부하, n=3"이라고 범위를 적는다.
