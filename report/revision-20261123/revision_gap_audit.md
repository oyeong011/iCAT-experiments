## 2. 조사 중 새로 발견한 문제 (우선 확인)

- **같은 arm 47의 mixY WAF가 실행 시기에 따라 다르다.**
  - 10월 실행(`9fde0ea4…`, 10-10)은 2.864, 11월 실행(`138024d0…`, 11-20)은 3.233이었다.
  - 단계 S01–S02는 같고, 첫 Varmail 단계(S03)부터 갈린다.
- 11월 V4는 Varmail 구간 창의 70–90 %를 arm 47로 돌았는데, 단계 WAF가 11월 sg-arm47과 거의 같았다. 그래서 빌드보다 시기 차이를 의심한다.
- 이를 판정하려고 E0(2.3시간)를 진행 중이다.
- **영향:**
  - 다른 달의 실행끼리 하는 비교는 확인 전까지 보류한다. 예: 11-23 SmartGC 보고서의 "V4가 CAT-47보다 0.7 % 낮음", 논문의 9월 표와 11월 결과를 섞는 비교.
  - 앞으로 하는 비교 실험은 모두 같은 배치에서 기준선까지 다시 돌린다.

## 3. 현재 환경에서 입증할 수 없는 것

- **실제 SSD에서의 CPU와 메모리 비용:** 이 환경은 RAM 기반 에뮬레이터다. 커널 스레드에는 RSS가 없다. 에뮬레이터의 GC는 데이터를 복사하지 않는다.
- **재탐색 중 CPU 실측 (기존 실행):** 계측하지 않은 빌드였다. 다시 측정하려면 E3가 필요하다.
